# PromotionStatus

`new` — the key does not yet exist in Live. `changed` — it exists in Live and differs. `identical` — it exists and matches, so promotion is a no-op. 

## Enum

* `NEW` (value: `'new'`)

* `CHANGED` (value: `'changed'`)

* `IDENTICAL` (value: `'identical'`)
